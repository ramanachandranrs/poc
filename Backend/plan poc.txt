Week 1: Data Mockups & Baseline Foundation (✅ COMPLETED)
Objective: Establish the data pipelines and create visibility into current inventory health without waiting for live IT system integration.
Mock Connectors & Schemas: Designed a unified SQLite database mirroring the exact schemas of Wipro DMS (Dealership Operations), SAP B1 (Enterprise Inventory), and Manesar Rail (Logistics).
Illustrative Seed Data: Built a Python script (generate_data.py) using Faker to programmatically generate an initial dataset (4,000 vehicles, 2,500 bookings) intentionally engineered with business friction (aging stock, stockouts, transit delays).
API Integration Layer: Wrapped the database in a fully functional, CORS-enabled FastAPI application to simulate live enterprise endpoints, making the environment instantly "agent-ready."
Baseline Analytics: Ran a baseline data science script to calculate Reorder Points (ROP) and flag the initial aging vehicles, establishing the "before" snapshot for ROI comparison.
Week 2: Intelligence Prototyping (⏳ IN PROGRESS)
Objective: Transform the raw data into an analytical engine that can generate actionable, intelligent recommendations.
Production-Grade Data Synthesis (Current Step): Use MOSTLY AI to ingest the Week 1 seed data and generate a massively scaled, 10x synthetic dataset that deep-learns the complex, non-linear relationships of the dealer network.
Initial ML Prototype (Demand Forecasting): Build a basic machine learning model to predict 30-day demand for specific vehicle variants and spare parts at the dealership level.
Heuristic Transfer Utility Score: Develop the core Python logic that calculates the net value of moving inventory. It will weigh the financial benefit of transferring an aging vehicle against the estimated transportation cost.
GenAI Prompt Templates: Draft the three core "hats" the AI Copilot will wear:
B2B Negotiation: Dealer-to-dealer transfer requests.
B2C Sales: Customer outreach for aging inventory.
Operational Alerts: Logistics delays and critical part stockouts.
Week 3: Guided Pilot & Impact Validation (🚀 UPCOMING)
Objective: Validate the AI's logic in a simulated live environment and quantify the potential business value.
Guided Assistant Interface: Deploy the AI not as an autonomous agent, but as a "guided assistant." We will build a basic interface (either a mock UI or a Twilio WhatsApp integration) where the AI surfaces its recommendations for human review and approval.
Shadow Mode Deployment: Run the AI Copilot against the massive MOSTLY AI dataset, simulating a live rollout to a 10-dealer pilot group.
Quantify Potential Impact (24-Hour ROI): Measure the exact success of the AI against the Week 1 baseline. We will output a final report calculating the projected reduction in inventory days, the drop in stockout rates, and the total floorplan interest saved.
